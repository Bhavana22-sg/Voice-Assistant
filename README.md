Voice-Assistant

📌 Project Overview

A Python-based Voice Assistant that listens to the user's voice commands, understands them using speech recognition, and performs different actions such as opening applications, websites, searching the web, and providing basic information.

🎯 Objective

To develop a simple voice-controlled assistant using Python.
To convert spoken commands into text.
To open applications and websites using voice commands.
To provide basic information such as time and date.
To understand and respond to different user commands.

⚙️ Project Workflow

Voice Input → Speech Recognition → Command Processing → Action → Voice Response

🛠️ Technologies Used

🐍 Python
🎤 SpeechRecognition
🔊 pyttsx3
🌐 Webbrowser
💻 OS module
🎙️ PyAudio

✨ Features

🎤 Voice command recognition
📱 Opens applications such as Calculator, Notepad, Paint, Chrome, Word and Excel
🌐 Opens websites such as YouTube, Google, Gmail and GitHub
🔎 Performs Google searches
🕐 Provides current time and date
🗣️ Gives voice responses
❌ Voice command to exit the assistant

📊 Result

The Voice Assistant successfully recognizes spoken commands and performs the requested actions, such as opening applications and websites.
